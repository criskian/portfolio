# Security Policy

This repository is a static personal website with no backend and no user data.

If you find a security issue (for example, a vulnerable dependency that is actually
reachable, or a way to inject content into the page), please **do not open a public
issue**. Report it privately through
[GitHub Security Advisories](https://github.com/criskian/portfolio/security/advisories/new)
or via [LinkedIn](https://www.linkedin.com/in/cristian-molina-ai-cloud/).

You can expect an acknowledgement within a few days. Supported version: the latest
commit on `main`.
